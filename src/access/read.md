
**************필드 및 메서드 접근제어자

private -> default -> protected -> public순

private : 모든 외부 호출 불가, 자기 클래스 내부에서만 사용 가능

default : 같은 패키지만

protected : 같은 패키지만 + 자기클래스 및 상속클래스내부만 사용가능

public : 어디에서나 사용 가능



**************클래스 접근제어자

public, default만 사용가능

public클래스는 반드시 파일명과 같아야 한다. (하나의 자바 파일에 public클래스는 한개만 사용 가능)

하나의 자바파일에 default클래스는 무한정 사용 가능



***********캡슐화
우리가 자동차를 운전할 때 엑셀과 브레이크(public 기능)만 알면 되지,
엔진 내부의 복잡한 동작 원리(public아닌 멤버함수?)나 
부품(private 데이터/기능)까지 알 필요는 없는 것과 같습니다.
